A useful first look, with limits

Checks empty and repeated headers (trimmed, case-insensitive), uneven rows, exact repeated data records, surrounding whitespace and potential spreadsheet formula prefixes. Negative values may be flagged. Nothing is automatically changed or rewritten.

This is a generic structural check, not a correctness, import-compatibility or security guarantee. AI-generated prototype code can contain errors. A result with no findings does not establish that data is safe or ready to import.
